# NUMSLIDE

A game built with [Godot 4.7](https://godotengine.org/) (Mobile renderer).

> Gameplay description to be filled in as the project takes shape.

## Requirements

- Godot Engine **4.7.1-stable** (or newer 4.7.x)

## Getting started

1. Clone the repo:
   ```sh
   git clone https://github.com/sagokriyo/NUMSLIDE.git
   cd NUMSLIDE
   ```
2. Open the Godot project manager, click **Import**, and select `project.godot`.
3. Press **F5** to run.

## Project layout

| Path | Purpose |
| --- | --- |
| `project.godot` | Engine/project configuration |
| `icon.svg` | Application icon |
| `.godot/` | Local editor cache — not tracked |

## Editing in VS Code

`.vscode/settings.json` points the [godot-tools](https://marketplace.visualstudio.com/items?itemName=geequlim.godot-tools)
extension at the local Godot binary. Update `godotTools.editorPath.godot4` if your
Godot install lives elsewhere.
